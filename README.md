## 📚 How to Read Your Exported Logs

Different formats require different viewing methods:

### CSV Files
Open with Excel, Google Sheets (upload to Google Drive), or free alternatives like LibreOffice Calc. You'll see rows of events with columns showing details like date, time, source, and message.

### TXT Files
Open with Notepad or any text editor. Each event will appear as readable text.

### XML Files
Open with any web browser (Chrome, Edge, Firefox) or use a text editor. The format is structured but readable.

### EVTX Files
These are special Windows files. You can open them by:
1. Pressing `Windows + R` on your keyboard
2. Typing `eventvwr.msc` and pressing Enter
3. In Event Viewer, click "Action" then "Open Saved Log"
4. Navigate to your file and open it
